# Pylon 使用指引

> v2.3.3（2026-11-15）：按当前版本实测通过的行为写成。以前的版本（v2.1.3 之前）有多种网络模式、网页面板，那些都已删除，本文只写现在这版。

## 一、这是什么

Pylon 是跑在你 Windows 电脑上的一个本地小服务：云端的 AI 助手通过 Tailscale 直连它，在你指定的文件夹里读写文件、跑白名单命令，再把成果写回本地。

- 只能动一个文件夹：`work` = 你在配置里填的那一个，出这个文件夹一步都走不出去。
- 只在程序开着的时候能用；关掉窗口（或托盘退出）即断开。
- 监听端口：默认 `8765`，绑 `0.0.0.0:8765`，只走 Tailscale 私网，不走公网。
- 没有别的网络模式。Cloudflare Tunnel、反向 WebSocket、iroh P2P 都已在 v2.1.3 删除，只剩 Tailscale。

## 二、启动、停止、重启

| 操作 | 怎么做 |
|---|---|
| 启动 | 双击项目目录里的 `start.bat`（先杀旧进程、再 `cargo build --release`、最后拉起程序），等 Pylon 窗口打开 |
| 停止 | 右键系统托盘图标 → 退出 Pylon；或点窗口里的 [⏻ 退出] |
| 重启（升级后） | 关窗口 → 再双击 `start.bat`；程序本身升级必须走这一步，改配置不用（配置保存后 0.5 秒内热生效） |
| 确认跑起来了 | 窗口顶栏看版本号，或查 `/health` 报的版本 |

双击两次也不会起两个实例——第二个实例会唤醒已有的窗口后退出。

## 三、控制面板

面板是一个 Tauri 2 桌面窗口（不是浏览器网页）。`http://127.0.0.1:8765/` 现在只返回一个小 JSON 状态，`/ui/*` 接口经 HTTP 一律 403，只能由本机 Tauri 界面内部调用。

窗口顶部是唯一一行 60px 单层顶栏：左侧是猫标 + Pylon + 版本徽章 + 运行状态，右侧是三档权限分段切换器、[主题] [设置] 红底白字 [熔断]、最小化 / 最大化 / 关闭 / 退出。

面板里能看到：待办审批（置顶横幅）、KPI、操作热力图、程序胶囊（绑定的主程序单文件）、后台任务、实时动态时间轴（最新在前）。

窗口关掉即销毁（释放 WebView2，待机约 5MB），托盘双击或右键「打开面板」可重建；关窗前自动保存窗口位置和大小，下次打开恢复。

## 四、权限三档

| 档位 | 含义 |
|---|---|
| 请求批准（`ask_always`） | 所有写操作和命令都要你面板点允许 |
| 帮我批准（`smart_auto`，默认） | 白名单内的直接跑，白名单外的挂起等你点允许，60 秒不点算拒绝 |
| 完全访问权限（`full_access`） | 白名单外的开发命令也能直接跑 |

**三条红线，三档都一样，谁都绕不过去：**

1. `cmd`、`powershell`、`pwsh`、`bash`、`sh` 这些 shell 永远禁。
2. 命令的工作目录永远锁在 `work` 文件夹内。
3. `bridge-config.json` 永远不能远程改；里面的 Token 别发给任何人。

另外：超时默认 300 秒（最长 1800 秒），`stdout`/`stderr` 各最多 512KB。

## 五、文件操作

| 接口 | 作用 | 限制 |
|---|---|---|
| `GET /api/list` | 列目录 | 敏感文件（`bridge-config.json`、`pylon-activity.log`）不显示 |
| `GET /api/read` | 读文本文件 | UTF-8，单文件 2MB 上限；禁读敏感文件 |
| `POST /api/write` | 写文本文件 | 同上；覆盖前自动打快照（见第八节） |
| `POST /api/patch` | 行级修补 | `search` 必须恰好出现 1 次；CRLF / LF 无感匹配，写回保留原换行符 |
| `GET /api/search` | 代码检索 | 支持正则、`case_sensitive`，最多 100 条 |
| `POST /api/mkdir` | 建目录 | — |
| `POST /api/trash` | 软删除 | 移入 `work/.pylon_trash/<时间戳>_<原名>`，不是物理删除 |
| `POST /api/rename` | 重命名 / 移动 | 目标需审批；覆盖前自动打快照 |
| `GET /api/read_base64`、`POST /api/write_base64` | 二进制文件读写 | 上限 10MB；写非 UTF-8 目标会直接拒绝，不会毁二进制 |
| `GET /api/program`、`POST /api/program` | 主程序单文件 | 整文件覆写或行级修补；支持 `expected_sha256` 乐观锁（不匹配 409）与 `run_argv` 改后即跑 |
| `GET /api/changes?since_ms=` | 增量变更感知 | 列出最近改动的文件 |

删文件一律走回收站，不再需要手动删。

## 六、跑命令

**默认白名单 6 条，直接跑：** `cargo run`、`cargo test`、`cargo check`、`cargo build`、`cargo --version`、`rustc --version`。

**审批表 2 条：** `git push`、`python`（跑 `.py` 脚本）。在「帮我批准」下，远程调用要你面板点允许；本机面板点按直接跑（点按本身就是确认）。

**Python 的用法：**

- 写脚本再跑：先把 `.py` 文件写进 `work` 文件夹，再调 `python 脚本.py`，适合批量改文件、解析数据、生成东西。
- `python -c` / `python -m`（除 `python -m pip --version` 外）一律 403，任何权限下都不给跑；`python` 只能跑白名单内已存在的 `.py` 脚本。
- `python --version` 不在默认白名单里，走审批表（`["python"]` 前缀命中），需要你点允许。

**别用它跑常驻服务**：跑完就退出的命令（编译、测试）才合适。长活走后台任务（见第十节）。

## 七、审批怎么处理

- 新的写操作 / 命令触发审批时，面板顶部出现审批横幅，点允许或拒绝；60 秒不点算拒绝。
- 审批横幅带红绿 Diff 预览（`-` 行暗红、`+` 行暗绿），一眼看出改了什么；同时右下角弹出 Windows 原生托盘气泡「Pylon 待批准操作」，点气泡唤醒面板。
- 审批队列上限 16 条，满了返回 429。

## 八、快照与回滚

每次写、修补、软删除、重命名覆盖已存在文件前，自动把原文件存一份快照（内存环形队列，上限 30 条；快照总字节上限 32MB；新建文件记为「不存在」）。

- 面板「实时动态时间轴」里，带快照的操作右侧有 **[回滚]** 按钮，点一下 1 秒还原；回滚本身也会再拍一张保护快照，可以二次反悔。
- 活动日志同时落盘到 exe 同目录的 `pylon-activity.log`（超 5MB 自动轮转为 `.old`），启动时读末尾 50 条恢复。

## 九、后台任务

编译、测试这种长活可以走异步任务，不用占着一次请求等 30 分钟：

| 接口 | 作用 |
|---|---|
| `POST /api/tasks/start` | 启动异步长任务（并发上限 8，超限 429） |
| `GET /api/tasks/status?id=&tail_bytes=` | 任务状态 + stdout/stderr 尾部（UTF-8 边界对齐） |
| `GET /api/tasks/list` | 列出任务 |
| `POST /api/tasks/stop` | 停止任务（关 Job 句柄，系统清进程树） |

每个任务进专属 Windows Job Object，超时或停止时进程树一并被系统清理。面板「任务」区能看到每个任务的输出和 [查看输出] 日志弹窗。

注意：桥单次 `/api/run` 最长 1800 秒（30 分钟），长活必须拆成 ≤30 分钟的块，靠 checkpoint 断点续跑，不能靠后台常驻进程。

## 十、常见问题

| 现象 | 原因 / 办法 |
|---|---|
| 重编报 `failed to remove ....exe / os error 5` | 旧程序还在运行、exe 被 Windows 锁住了；先关桥窗口，或 `taskkill /F /IM muse-local-bridge.exe` 再编 |
| 面板打不开 | 先看托盘图标在不在；托盘双击或右键「打开面板」重建窗口。`http://127.0.0.1:8765/` 现在只返回 JSON 状态，不是面板入口 |
| 面板一片空白、按钮都没反应 | 前端脚本可能坏了；看窗口顶部有没有红色错误横幅，上面会写具体错误；先报给 Astro，别自己乱改 `ui/` |
| 命令跑一半没反应 | 可能撞了 300 秒超时或 512KB 输出上限；拆小步跑，或走后台任务分段处理 |
| `python -c` 报 403 | 正常，任何权限下都禁；改成写 `.py` 脚本再跑 |
| 版本号对不上 | Cargo.toml、`bridge.rs` 的 `VERSION` 常量、面板徽章必须同步改；发现对不上先问 Astro |

## 十一、更新流程

1. 改代码 → 云端 `cargo check` 零警告、`cargo test` 全过（Windows 102 项、Linux 100 项）。
2. 经桥同步到你电脑 → 你那边 `cargo check`、`cargo test` 再验一遍。
3. 关窗口重跑 `start.bat` → 验 `/health` 版本号，确认新版在跑。
