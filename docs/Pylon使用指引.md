# Pylon 使用指引

> v1.0.3（2026-11-09）：按真机实测通过的行为写成。最终版放在 `119` 文件夹（Pylon 的 `work` 目录），由 Astro 经桥写入。

## 一、这是什么

Pylon 是跑在你 Windows 电脑上的一个本地小服务：云端的 Astro 通过 Tailscale 直连它，在你指定的文件夹里读写文件、跑白名单命令，再把成果写回本地。

- 只能动一个文件夹：`work` = `C:\path\to\your\workspace`，出这个文件夹一步都走不出去。
- 只在程序开着的时候能用；关掉窗口（或托盘退出）即断开。
- 监听端口：默认 `8765`；`tailscale_or_local` 模式绑 `0.0.0.0:8765`，其余网络模式只绑本机 `127.0.0.1:8765`。

## 二、启动、停止、重启

| 操作 | 怎么做 |
|---|---|
| 启动 | 双击项目目录里的 `start.bat`，等 Edge 自动弹出控制面板 |
| 停止 | 右键系统托盘图标 → 退出 Pylon（v1.0.0 起没有常驻窗口了，关托盘即断开） |
| 重启（升级后） | 关窗口 → 再双击 `start.bat`；程序本身升级必须走这一步，改配置不用（v0.9.0 起配置保存后 0.5 秒内热生效） |
| 确认跑起来了 | 面板顶栏看版本号，或问 Astro 查 `/health` 报的版本 |

v1.0.0：启动后不再挂着黑色 CMD 窗口，只留右下角系统托盘；`start.bat` 改为编译完后台拉起 exe、自动关闭 CMD。双击两次也不会起两个实例——第二个会直接打开面板后退出。

## 三、控制面板

- 地址：`http://127.0.0.1:8765/`（仅本机能打开，远程打不开）。
- 顶栏右侧 **权限 Popover**：三档随时切换，立即生效，不用重启。
- 面板里能看到：待办审批、配置与网络模式、服务状态、操作热力图、实时动态时间轴（最新在前）。

## 四、权限三档

| 档位 | 含义 |
|---|---|
| 请求批准（`ask_always`） | 所有写操作和命令都要你面板点允许 |
| 帮我批准（`smart_auto`，默认） | 白名单内的直接跑，白名单外的挂起等你点允许，60 秒不点算拒绝 |
| 完全访问权限（`full_access`） | 白名单外的开发命令也能直接跑（`node`、`npm`、`go`、`python -c` 等） |

**三条红线，三档都一样，谁都绕不过去：**

1. `cmd`、`powershell`、`pwsh`、`bash`、`sh` 这些 shell 永远禁（你定的永久规则）。
2. 命令的工作目录永远锁在 `work` 文件夹内。
3. 超时默认 300 秒（最长 1800 秒），`stdout`/`stderr` 各最多 512KB。

另外：`bridge-config.json` 永远不能远程改；里面的 Token 别发给任何人。

## 五、文件操作

| 接口 | 作用 | 限制 |
|---|---|---|
| `GET /api/list` | 列目录 | — |
| `GET /api/read` | 读文件 | UTF-8 文本，单文件 2MB 上限 |
| `POST /api/write` | 写文件 | 同上；覆盖前自动打快照（v1.0.0，见下） |
| `POST /api/patch` | 行级修补 | 同上 |
| `GET /api/search` | 代码检索 | 正则模式 |
| `POST /api/trash`（v1.0.0） | 软删除 | 移入 `work/.pylon_trash/<时间戳>_<原名>`，不是物理删除 |
| `POST /api/rename`（v1.0.0） | 重命名/移动 | 覆盖前自动打快照 |
| `GET /api/read_base64`、`POST /api/write_base64`（v1.0.0） | 二进制文件读写 | 上限 10MB |

删文件一律走回收站，不再需要手动删。

## 六、跑命令

**白名单 13 条，直接跑：** `cargo run`、`cargo test`、`cargo check`、`cargo build`、`cargo --version`、`rustc --version`、`git --version`、`git status`、`git log --oneline -20`、`git diff`、`git pull`、`python --version`、`python -m pip --version`。

**审批表 2 条：** `git push`、`python`（跑 `.py` 脚本）。在「帮我批准」下，远程调用要你面板点允许；本机面板点按直接跑。

**Python 两种用法：**

- 一行命令：`python -c "..."`，适合小段逻辑、查环境、算个数（仅 `full_access` 下能直接跑）。
- 写脚本再跑：先把 `.py` 文件写进 `work` 文件夹，再调 `python 脚本.py`，适合批量改文件、解析数据、生成东西。

## 七、审批怎么处理

- 新的写操作/命令触发审批时，面板顶部出现审批横幅，点允许或拒绝；60 秒不点算拒绝。
- v1.0.0：审批横幅带红绿 Diff 预览（`-` 行暗红、`+` 行暗绿），一眼看出改了什么；同时右下角弹出 Windows 原生托盘气泡「Pylon 待批准操作」，点气泡唤醒面板。

## 八、网络模式（面板设置里改，保存即热生效）

| 模式 | 一句话 |
|---|---|
| `tailscale_or_local`（默认） | Tailscale 私网直连 |
| `cloudflare_tunnel` | 经 Cloudflare Tunnel 出站 |
| `ws_reverse` | 反向 WebSocket 长连接（v1.0.0 支持 `wss://` 加密） |
| `iroh_p2p` | 中继长轮询（v1.0.0 支持 `https://` 加密中继地址） |

## 九、快照与回滚（v1.0.0）

每次写、修补、软删除、重命名覆盖已存在文件前，自动把原文件存一份快照（内存环形队列，上限 30 条，单文件 ≤2MB；新建文件记为「不存在」）。

- 面板「实时动态时间轴」里，带快照的操作右侧有 **[↶ 回滚]** 按钮，点一下 1 秒还原，弹 Toast `✓ 已回滚 <路径>`。
- 另有 `GET /ui/snapshots` 与 `POST /ui/revert` 接口。
- 活动日志同时落盘到 exe 同目录的 `pylon-activity.log`（超 5MB 自动轮转为 `.old`），启动时读末尾 50 条恢复。

## 十、常见问题

| 现象 | 原因 / 办法 |
|---|---|
| 大文件写入被断连、无报错 | v0.9.0 的真 bug（accept 继承非阻塞，读到一半撞 `WouldBlock`）；v0.9.1 已修，重启到 v0.9.1 即解决 |
| 重编报 `failed to remove ....exe / os error 5` | 旧程序还在运行、exe 被 Windows 锁住了；先关桥窗口，或 `taskkill /F /IM muse-local-bridge.exe` 再编 |
| 面板打不开 | 先看托盘图标在不在（v1.0.0 起没有常驻窗口了）；再确认地址是 `http://127.0.0.1:8765/`，远程打不开是正常的 |
| 面板一直转圈、动态和审批都加载不出来 | v1.0.2 起面板不再用动态密钥，重启后自动恢复，不用按 F5；如果还转圈，关掉 Edge 窗口重开 `http://127.0.0.1:8765/`（最后一次旧页面需要手动换掉，此后重启都不用管了） |
| 命令跑一半没反应 | 可能撞了 300 秒超时或 512KB 输出上限；拆小步跑，或让 Astro 分段处理 |
| 版本号三处对不上 | Cargo.toml、`bridge.rs` 的 `VERSION` 常量、面板徽章必须同步改；发现对不上先问 Astro |

## 十一、更新流程（给 Astro 的约定）

1. 改代码 → 云端 `cargo check` 零警告、`cargo test` 全过。
2. 经桥同步到你电脑 → 你那边 `cargo check`、`cargo test` 再验一遍。
3. 关窗口重跑 `start.bat` → Astro 验 `/health` 版本号，确认新版在跑。
